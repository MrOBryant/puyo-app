# PUYO App — Prototype

Prototype konsep aplikasi PUYO untuk tugas Strategic Management (rekomendasi strategi Market Penetration).
**Bukan aplikasi resmi PUYO.** Pesanan, pembayaran, rider, dan poin hanya simulasi; data tersimpan di perangkat pengguna saja.
Logo, foto produk, dan daftar gerai diambil dari puyodesserts.com untuk keperluan tugas.

## Chatbot WhatsApp PUYO Member (prototype)

`chat.html` adalah prototype chatbot WhatsApp "PUYO Group" untuk Loyalty Membership Program (bab 3.2.2 paper).
Buka `chat.html` di HP. Menu ⋮ → **Simulasi Kasir** untuk beli di gerai, daftar member, kumpulkan stamp (5 stamp = 1 PUYO gratis),
**hari ini ulang tahunku** untuk voucher ulang tahun, dan tanya bebas soal Silky Desserts, PUYOTEIN, gerai, promo, dan data.
Bot berbasis aturan (bukan AI), semua data tersimpan di browser HP. Bukan akun resmi PUYO.
